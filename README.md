# 🥖 Sourdough Bakery Website

A premium bakery website built for a handmade sourdough brand.

---

## ✨ Features

- Modern and elegant bakery design
- Fully responsive layout for desktop, tablet, and mobile
- Arabic RTL support
- Smooth animations and transitions
- Dynamic products loaded from JSON files
- WhatsApp ordering integration
- Brand information management
- SEO optimized
- Decap CMS integration
- GitHub and Netlify deployment
- Image upload support through CMS
- No database required

---

## 📄 Pages

- Home
- Menu
- About Brand
- Contact

## 🛠 Technologies Used

- HTML5

- GitHub

---

## ⚙️ CMS Access

The website content can be managed through the admin panel:

```text
/admin
```

The client can update the website content directly through Decap CMS without editing code.

### Editable Content

- Brand information
- Logo
- Hero section
- About section
- Products
- Product images
- Contact information
- WhatsApp number
